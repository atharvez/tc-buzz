# TC Buzz

A real-time social platform for tech communities -- discussions, announcements, and the latest in tech.

**Live:** [tc-buzz.vercel.app](https://tc-buzz.vercel.app)

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 15, TypeScript, Tailwind CSS |
| Database | Supabase (PostgreSQL + Realtime) |
| Auth | Supabase Auth |
| Deployment | Vercel |

## Features

- Live feed -- real-time tech news and discussions
- Threaded comments -- nested discussion system
- Upvotes -- community-driven content ranking
- Tag browsing -- filter by technology/topic
- Dark mode -- easy on the eyes

## Getting Started

```bash
git clone https://github.com/atharvez/tc-buzz.git
cd tc-buzz
npm install
cp .env.example .env.local
npm run dev
```
